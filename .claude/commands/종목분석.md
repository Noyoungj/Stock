사용자가 **$ARGUMENTS** 종목 분석을 요청했습니다.

아래 순서로 진행하세요.

## 1단계: 종목코드 확인

입력값이 6자리 숫자(예: 005930)면 그대로 종목코드로 사용합니다.
그렇지 않으면 아래 명령어로 종목코드를 검색하세요:

```bash
cd ~/Desktop/Test && source .venv/bin/activate && python3 lookup.py $ARGUMENTS
```

결과에서 종목코드를 확인하세요. 여러 개가 나오면 가장 관련성 높은 것을 선택하고, 애매하면 사용자에게 어떤 종목인지 물어보세요.

## 2단계: 데이터 수집

찾은 종목코드(예: CODE)와 회사명(예: NAME)으로 아래 명령어를 실행하세요:

```bash
cd ~/Desktop/Test && source .venv/bin/activate && python3 analyze.py CODE NAME
```

## 3단계: 종합 분석

수집된 데이터를 바탕으로 아래 구조로 분석을 작성하세요.

### 한 줄 요약
지금 이 종목의 상황을 한 문장으로.

### 가격 흐름
최근 30일 흐름과 오늘 등락의 맥락을 설명하세요.

### 재무 해석
PER·PBR·ROE·배당수익률 등을 일반인이 이해하기 쉽게 풀어서 설명하세요. 숫자 나열이 아닌 "싼가? 비싼가? 수익성은?" 관점으로.

### 뉴스 이슈
최근 뉴스에서 주가에 영향을 줄 수 있는 내용을 짚어주세요.

### 공시 포인트
최근 공시 중 투자자가 주목해야 할 내용을 설명하세요.

### 체크포인트
- ✅ 긍정적인 요소
- ⚠️ 주의가 필요한 요소
- ❓ 추가 확인이 필요한 요소

### 언제 들어가는 게 좋을까?
수집한 데이터(현재가 위치, 이동평균 추세, 밸류에이션, 뉴스/공시 흐름)를 종합해서 아래 관점으로 솔직하게 의견을 주세요.

- **지금 당장 들어가도 될까?** — 현재 가격이 고점/저점 대비 어느 위치인지, 추세가 살아있는지
- **기다린다면 어떤 신호를 보고 들어갈까?** — 구체적인 조건 (예: 특정 가격대, 이평선 정배열 확인, 실적 발표 후 등)
- **피해야 할 상황은?** — 지금 들어가면 안 되는 이유가 있다면 솔직하게
