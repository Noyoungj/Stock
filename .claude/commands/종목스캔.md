사용자가 **$ARGUMENTS** 종목에 대한 스크리닝을 요청했습니다.

## 1단계: 종목코드 확인

입력값이 6자리 숫자면 그대로 사용, 아니면 검색:

```bash
cd ~/Desktop/Test && source .venv/bin/activate && python3 lookup.py $ARGUMENTS
```

여러 개가 나오면 가장 관련성 높은 것을 선택하세요. 애매하면 사용자에게 물어보세요.

## 2단계: 스크리닝 실행

```bash
cd ~/Desktop/Test && source .venv/bin/activate && python3 stock_screen.py CODE NAME
```

## 3단계: 종합 분석

스크리닝 결과를 바탕으로 아래 구조로 분석하세요.

### 스크리닝 결과 요약
4가지 조건 충족 여부를 표로 정리하고 최종 점수 명시.

### 각 조건 해석
단순 O/X가 아니라 "왜 충족됐는지 / 왜 미충족인지" 맥락 설명.

### 언제 들어가는 게 좋을까?
점수와 조건 내용을 바탕으로 솔직한 진입 타이밍 의견.
- 지금 당장 vs 기다리기
- 기다린다면 어떤 신호를 보고 들어갈지
- 손절 기준
