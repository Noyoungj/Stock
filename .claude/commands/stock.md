## 📈 주식 관련 커맨드 목록

### 분석
| 커맨드 | 설명 |
|--------|------|
| `/종목분석 <종목명>` | 개별 종목 심층 분석 (가격·재무·뉴스·공시) |
| `/종목스캔 <종목명>` | 4가지 조건 스크리닝 (저평가·추세·거래량·공시) |
| `/종목리뷰` | 저장된 리포트 기반 워치리스트 종합 분석 |

### 시장
| 커맨드 | 설명 |
|--------|------|
| `/시장스캔` | 오늘 안 오른 유망 종목 탐색 |
| `/시장조사 <키워드>` | 업종·테마 리서치 (예: `/시장조사 반도체`) |

### 터미널 명령어
| 명령어 | 설명 |
|--------|------|
| `stock` | 워치리스트 전체 브리핑 + MD 저장 |
| `stock add <종목명>` | 워치리스트 추가 |
| `stock remove <종목명>` | 워치리스트 삭제 |
| `stock list` | 워치리스트 목록 |
| `stock-scan` | 시장 스캔 (터미널) |
| `stock-screen <코드>` | 종목 스크리닝 (터미널) |
