오늘 시장 흐름을 분석해서 아직 안 오른 유망 종목을 찾아줘.

## 1단계: 스캔 실행

```bash
cd ~/Desktop/Test && source .venv/bin/activate && python3 market_scanner.py
```

## 2단계: 종합 분석

스캔 결과를 바탕으로 아래 구조로 분석을 작성해줘.

### 오늘 시장 요약
KOSPI/KOSDAQ 흐름과 전반적인 시장 분위기를 한 줄로.

### 주목 업종
워밍업으로 선별된 업종들이 왜 오르고 있는지 맥락 설명.
(최근 뉴스나 글로벌 흐름과 연결해서 설명해줘)

### 후보 종목 분석
각 후보 종목에 대해:
- 왜 지금 주목할 만한지
- 4가지 조건 중 어떤 게 충족됐는지
- 어떤 리스크가 있는지

### 언제 들어가는 게 좋을까?
후보 종목별로 구체적인 진입 타이밍 의견.
- 지금 바로 vs 눌림 기다리기
- 어떤 신호가 나오면 진입할지
- 손절 기준은 어디로 볼지

### 최종 추천
후보 중 가장 매력적인 1~2종목을 골라서 이유를 솔직하게.

> 이 분석은 정보 제공 목적입니다. 투자 결정은 본인 판단으로 하세요.
