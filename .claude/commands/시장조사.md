사용자가 **$ARGUMENTS** 시장/섹터 조사를 요청했습니다.

## 1단계: 데이터 수집

```bash
cd ~/Desktop/Test && source .venv/bin/activate && python3 sector_research.py $ARGUMENTS
```

## 2단계: 종합 분석

수집된 데이터를 바탕으로 아래 구조로 분석하세요.

### 한 줄 요약
지금 이 섹터의 상황을 한 문장으로.

### 왜 지금 이 섹터가 주목받나?
섹터 평균 수익률과 뉴스를 연결해서 현재 시장의 관심이 집중되는 이유를 설명하세요.
글로벌 트렌드(AI 투자, 지정학, 정책 등)와 연결하면 더 좋아요.

### 섹터 내 종목 분석
- 가장 강하게 오른 종목과 이유
- 아직 덜 오른 종목 (상대적 약세)
- 재무적으로 가장 탄탄한 종목

### 리스크 요인
이 섹터에 투자할 때 주의해야 할 요인들.

### 주목할 종목 추천
섹터 내에서 가장 매력적인 1~2개 종목과 이유.
(재무 + 주가 위치 + 모멘텀 종합)

### 언제 들어가는 게 좋을까?
섹터 전체 타이밍과 종목별 진입 의견.

> 이 분석은 정보 제공 목적입니다. 투자 결정은 본인 판단으로 하세요.
