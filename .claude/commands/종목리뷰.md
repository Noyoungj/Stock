저장된 종목 리포트를 읽고 종합 분석을 해줘.

## 1단계: 저장된 리포트 목록 확인

```bash
ls -t ~/Desktop/Test/reports/*.md 2>/dev/null
```

파일이 없으면 "저장된 리포트가 없어요. 먼저 `stock` 을 실행해서 브리핑을 저장해주세요." 라고 안내하고 종료.

## 2단계: 각 리포트 파일 읽기

목록에 있는 모든 .md 파일을 Read 툴로 읽어.

## 3단계: 종합 분석 작성

읽은 내용을 바탕으로 아래 구조로 분석해줘.

### 오늘의 한 줄 시황
워치리스트 종목들의 전반적인 흐름을 한 문장으로.

### 종목별 요약
각 종목을 아래 형식으로 간결하게:

**[종목명]** — 현재가 / 등락률 / 추세
- 핵심 포인트 1~2개 (재무·뉴스·공시 중 가장 중요한 것)
- 체크포인트 (✅ 긍정 / ⚠️ 주의)

### 오늘 가장 주목할 종목
워치리스트 중 지금 가장 관심 가져야 할 종목과 이유.
(단순히 많이 오른 종목이 아니라, 뉴스·공시·밸류에이션·추세를 종합해서)

### 주의가 필요한 종목
리스크 신호가 있는 종목과 이유.

### 참고
> 이 분석은 저장된 리포트 기준입니다. 최신 데이터가 필요하면 `stock` 을 다시 실행하세요.
> 투자 결정은 본인 판단으로 하세요.
